# SDG Group Discussion (GD) AI Agent & Competition Prep System

An intelligent AI Agent built specifically for the **SDG Based Group Discussion Competition** (covering SDG 5: Gender Equality, SDG 9: Industry, Innovation and Infrastructure, and SDG 13: Climate Action).

---

## 🏆 Competition Overview & Agent Architecture

The competition consists of 3 phases (Total: 100 Marks):
1. **Phase I: SDG Prioritisation & Negotiation (25 Marks)**
   - *Agent Feature:* Generates persuasive advocacy hooks, urgency metrics, feasibility arguments, comparative defenses against other SDGs, and consensus-building frameworks.
2. **Phase II: Policy Analysis & Discussion (40 Marks)**
   - *Agent Feature:* Provides deep-dive briefs across all 6 required perspectives (Current challenges, Root causes, Policy/governance gaps, Stakeholders, Implementation barriers, Opportunities).
3. **Phase III: Lobbying & Plan of Action / PoA (35 Marks)**
   - *Agent Feature:* Generates a complete, professional 9-section Plan of Action covering objectives, beneficiaries, implementation strategies, roles, resources, timelines, outcomes, mitigation, and monitoring.

---

## 🚀 Quick Start

1. **Clone & Setup Environment:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. **Run the Interactive AI Coach:**
   ```bash
   python3 main.py
   ```

3. **Follow the interactive prompts** to select your SDG (SDG 5, 9, or 13) and generate winning strategies for any competition phase!
