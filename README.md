# SDG Group Discussion (GD) AI Agent & Web App

An intelligent AI Agent and Web App built specifically for the **SDG Based Group Discussion Competition** (covering SDG 5: Gender Equality, SDG 9: Industry, Innovation and Infrastructure, and SDG 13: Climate Action).

---

## 🏆 Competition Overview & Agent Architecture

The competition consists of 3 phases (Total: 100 Marks):
1. **Phase I: SDG Prioritisation & Negotiation (25 Marks)**
   - Generates persuasive advocacy hooks, urgency metrics, feasibility arguments, comparative defenses against other SDGs, and consensus-building frameworks.
2. **Phase II: Policy Analysis & Discussion (40 Marks)**
   - Provides deep-dive briefs across all 6 required perspectives (Current challenges, Root causes, Policy/governance gaps, Stakeholders, Implementation barriers, Opportunities).
3. **Phase III: Lobbying & Plan of Action / PoA (35 Marks)**
   - Generates a complete, professional 9-section Plan of Action covering objectives, beneficiaries, implementation strategies, roles, resources, timelines, outcomes, mitigation, and monitoring.

---

## 🌐 Running the Streamlit Web App

You can run the web app locally or deploy it on Streamlit Cloud to share with your friends and teammates:

```bash
# Install requirements
pip install -r requirements.txt

# Run Streamlit App
streamlit run app.py
```
